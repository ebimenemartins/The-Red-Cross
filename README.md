# The-Red-Cross: First Aid Educational Game



## 📖 About the Project
This project is currently being developed as a portfolio project for my COMP1405 class. "The Red Cross" is an interactive educational game designed to teach players the fundamentals of first aid. Through a series of engaging scenarios and mini-games, players learn how to respond to common emergencies, reinforcing the vital work and principles of the Red Cross.

## ✨ Features
* Players are given the opportunity to be one of three characters (nurse, assistant, driver) and are to pick what season of the year and location they would like to begin their first aid journey.
